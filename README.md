# 三つの区画 / Three Gates

ブラウザで遊べる謎解きゲームの試作版です。現時点は **v0.2**。数学知識の暗記やクイズ形式より、観察・推理・操作で謎を解く遊びを中心に開発しています。

## 遊び方

- 上部のチュートリアル10問は、数列・図形・条件推理などを使った簡単な小謎です。**○×ではなく数値を入力**して解答します。
- 完了すると、ホームの「区画1」に入力する最初のコードが得られます。
- ホームには区画1・2・3のコード入力欄と、「FINAL CODE」の入力欄があります。
- コードによって異なる記録や仕掛けを呼び出します。記録内の謎を解くと、別の区画に入力するコードが得られます。
- 仕掛け箱の操作や偽の正解の演出も仮実装しています。

## いま試せること

- チュートリアル全10問・数値入力・ヒント表示
- 最初の記録と次の記録の数値謎
- 3連ダイヤル式の仕掛け箱（独自の試作）
- 黒へのフェードアウト、文章の逐次表示、箱のフェードイン
- スマートフォン対応
- チュートリアル終了と箱の状態をブラウザ内に一部保存

## 今後の方針

チュートリアルも終盤の暗号に関係する設計とし、数字やコードに複数の意味を持たせます。p進数、非可換群、双曲幾何学、結び目理論、留数、カオス、フラクタル、自己言及などの高度な数学は、知識問題ではなく **必要に応じて謎を解くための道具** として取り入れる予定です。
