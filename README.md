# 三つの区画 / Three Gates

3つの区画でコードを使い分け、数値の謎と操作型パズルを解くオリジナルのブラウザゲームです。

**現在：PROTOTYPE v0.25**

## 遊び方

- **チュートリアル**：中学～高1程度の基礎方程式10問を数字入力で解きます。
- **区画1**：数列、暗号、記録を読み解いて次のコードを得ます。
- **区画2**：別の仕掛けや規則を解き、区画3などのコードを得ます。
- **区画3**：入力コードごとに異なる、実際に手を動かすミニゲームが始まります。

## 数字の箱（区画3のコード「OPEN」）

箱入り娘風のオリジナル操作型パズル。4×5の盤面で、見た目では大きな **5** の箱が最上段にあります。画面の案内にはあえて「一番大きい2」と書かれており、数字の食い違いが伏線です。実際には大きな5の箱を下辺中央の出口まで移動させるとクリアできます。

すべてのステージで**大きな「5」の箱は最上段の中央から開始**し、**盤面の空きは「1」の駒2個分だけ**です（盤面20マス相当に対し駒の合計18マス）。見た目はほぼ元の98%のサイズで、指で直接ドラッグできます。

1. **STAGE 1：1×14、5×1**。小駒を動かしながら大駒を下へ通す。最短27手。
2. **STAGE 2：1×8、0×3、5×1**。横長の駒が加わり、狭い通路で順序を考える。最短45手。
3. **STAGE 3：1×4、0×1、3×4、5×1**。縦長の駒も加わる高難度配置。最短116手。

手数はマス単位で駒を1つずつ動かす離散モデルでの最短値です。自由ドラッグでは手数が変わる場合があります。

3ステージすべてを攻略したときに、**区画1へ入力するコード**が現れます。途中ステージではコードは出ません。

### 操作方法

**タップ操作による自動移動は廃止しました。** 駒を指で押さえて好きな方向へ動かすと、斜め方向も含めて滑らかに移動し、**指を離した位置でそのまま止まります**。盤面に仕切り線はなく、**1×1駒を1マス幅の98％まで大きく戻しました**。駒の見た目と当たり判定を一致させ、少しだけ隙間を残しています。マス単位の吸着や勝手な位置合わせもありません。壁やほかの駒には衝突するため、すり抜けられません。短くタップするだけでは移動しません。指やマウスを離した瞬間は、直前に見えていた位置をそのまま保持します。狭い隙間でほんの少し引っかかったときは、動かしていない隣の駒が最大約0.35マス分だけ押し出されます。ただし壁を越えたり、ほかの駒に重なったりはできません。PCではマウスドラッグや補助的なキーボード操作にも対応します。「一手戻す」「このステージをやり直す」機能はそのままです。

### 隠し要素

盤面の駒や空きスペースを**30回短くタップ／クリック**すると、側面に「HP」の秘密表示が現れます。ドラッグ操作や長いスワイプは回数に含めません。回数は3ステージを通して数え、ステージ切り替え・一手戻す・再挑戦ではリセットしません。**「1」の箱はHP100、「0」「3」はHP200、大きな「5」はHP300**です。最初の30タップは内部で1ダメージずつ記録されますが、**10・20・30回目に全駒のHPが自動回復**します。この間は破壊されません。30回目に隠しHP表示が解禁され、以後は**タップした駒1個のHPだけが見える**仕様です。別の駒に触れると表示対象が切り替わります。31回目以降は駒を短くタップするたびに1ダメージ（空白のタップとドラッグではダメージなし）。HP0になった「0」「1」「3」は消滅して通路が空きます。大きな「5」のHP0では画面の文字・ボタン・駒・枠・背景が色ずれと不規則な揺れを起こし、**個々のパーツが上から順に、それぞれ別々に落下**して区画の選択画面へ戻されます。**初回とはページを開いてから最初の「数字の箱」への挑戦**です。過去のプレイで大きな「5」を壊していても、新しくページを開いたら必ず**30回でHP表示・大きな「5」はHP300**から始まります。**同じページ内で大きな「5」を壊して区画選択に戻り、もう一度 `OPEN` で入ったときだけ**2回目扱いです。以前の版が残したCookie・ブラウザ保存情報・URLの `tg5=1` は初回判定に使わず、起動時に削除します。**2回目以降は隠しHPを10回タップで解禁**し、**大きな「5」はHP1で開始**します。最初の10回は破壊されず、10回目でほかの駒が自動回復しても大きな「5」のHPは1のままです。**11回目以降に大きな「5」を1回タップするとHP0になり、再び崩壊が始まります。**画面内の日本語を含む単語・文字と駒・枠がそれぞれ別々に画面中を飛び回り、**突然一斉に止まってから上から順に落下**します。高速の白色ストロボは使わず、OSの視差効果を減らす設定にも対応しています。入力済みコード `OPEN` は保持され、再挑戦できます。

## 区画3の別コード

コード「PATH」「GLASS」「MIRROR」「ORIGIN」では、数字の箱とは別々の操作型ミニゲーム（迷路、消灯、反転スイッチ、記憶）が起動します。こちらは現時点では各1ステージのみです。

## 共通の仕組み

画面暗転・文書表示、複数のコード入力先、0と1の反転ルート、反転し忘れに対応した最終判定の試作、スマートフォン対応。
