# 三つの区画 / Three Gates

3つの区画でコードを使い分け、数値の謎と操作型パズルを解くオリジナルのブラウザゲームです。

**現在：PROTOTYPE v0.12**

## 遊び方

- **チュートリアル**：中学～高1程度の基礎方程式10問を数字入力で解きます。
- **区画1**：数列、暗号、記録を読み解いて次のコードを得ます。
- **区画2**：別の仕掛けや規則を解き、区画3などのコードを得ます。
- **区画3**：入力コードごとに異なる、実際に手を動かすミニゲームが始まります。

## 数字の箱（区画3のコード「OPEN」）

箱入り娘風のオリジナル操作型パズル。4×5の盤面で、大きな **5** を下辺中央の出口へ導きます。

今回は3ステージに変更しました：

1. **STAGE 1：1・5のみ**。小さな1×1の駒と大きな5の入門盤。
2. **STAGE 2：1・2・5**。横長の2が加わる盤。移動スペースを確保するため小駒の数を調整しています。
3. **STAGE 3：1・2・3・5**。縦長の3も加わる盤。

3ステージすべてを攻略したときに、**区画1へ入力するコード**が現れます。途中ステージではコードは出ません。

### 操作方法

**タップ操作による自動移動は廃止しました。** 駒を指で押さえて好きな方向へ動かすと、斜め方向も含めて滑らかに移動し、**指を離した位置でそのまま止まります**。盤面に仕切り線はなく、**1×1駒を1マス幅の88％まで大きく戻しました**。駒の見た目と当たり判定を一致させ、少しだけ隙間を残しています。マス単位の吸着や勝手な位置合わせもありません。壁やほかの駒には衝突するため、すり抜けられません。短くタップするだけでは移動しません。指やマウスを離した瞬間は、直前に見えていた位置をそのまま保持します。狭い隙間でほんの少し引っかかったときは、動かしていない隣の駒が最大約0.35マス分だけ押し出されます。ただし壁を越えたり、ほかの駒に重なったりはできません。PCではマウスドラッグや補助的なキーボード操作にも対応します。「一手戻す」「このステージをやり直す」機能はそのままです。

## 区画3の別コード

コード「PATH」「GLASS」「MIRROR」「ORIGIN」では、数字の箱とは別々の操作型ミニゲーム（迷路、消灯、反転スイッチ、記憶）が起動します。こちらは現時点では各1ステージのみです。

## 共通の仕組み

画面暗転・文書表示、複数のコード入力先、0と1の反転ルート、反転し忘れに対応した最終判定の試作、スマートフォン対応。
