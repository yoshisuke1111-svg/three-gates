# 三つの区画 / Three Gates

ブラウザで遊べる高難度謎解きゲームの試作版です。現在は操作感と画面遷移を確認するための **v0.1** で、本編の高難度数学謎は制作中です。

## 遊び方

[index.html](./index.html) をブラウザで開くか、GitHub Pages の公開ページから開始してください。

1. 上部のチュートリアル（全10問）を解き、最初のコードを入手します。
2. ホームの「1」「2」「3」には独立したコード入力欄があります。
3. 解いた謎から得たコードを対応する区画に入力すると、別の記録や仕掛けが表示されます。
4. 下部の「FINAL CODE」は本命の解答欄です。

## 実装済み

- PC・スマートフォン対応のホーム画面
- 10問の基本問題から始まるチュートリアル
- 区画ごとのコード認識と別画面への遷移
- ブラックアウト、文字の逐次表示、箱のフェードイン
- 操作可能な3連ダイヤル仕掛け箱（仮）
- 試験用の「正解。しかし真の正解ではない」演出
- 一部進行状況のローカル保存

## 予定している数学的要素

p進数、非可換群、双曲幾何学、結び目理論、複素積分・留数定理、カオス理論、ハウスドルフ次元、ゲーデル数・自己言及など。数学の名称を当てるクイズではなく、謎解きの途中でそれらの知識が必要になる形式を想定しています。

## 開発上の注意

現状はHTML/CSS/JavaScriptのみで動く静的な試作です。**公開リポジトリ内のJavaScriptは誰でも閲覧できるため、正解コードやネタバレを完全に隠すことはできません。** 本編のネタバレ対策は別途設計します。
