# 三つの区画 / Three Gates

3つの区画を行き来しながら、コード・数の規則・操作型の仕掛けを解くオリジナルのブラウザ謎解きゲームです。

**現在：PROTOTYPE v0.6（各区画にまず1つのメインステージ）**

## はじめ方

1. 上部のチュートリアル（簡単な方程式10問）を解き、区画1の最初のコードを得ます。
2. 区画1の記録を読み解くと区画2へのコードが得られます。
3. 区画2の仕掛けを解くと区画3のコードが得られます。
4. **区画3は数値入力型の問題ではなく、実際に操作して攻略するミニゲームです。** クリアすると別の区画のコードが現れます。

## 区画3の操作型ミニゲーム

区画3では、入力したコードごとに異なるゲームが起動します。現時点では、それぞれ**1ステージ**だけを実装しています。

- **数字の箱（OPEN）**：独自の箱入り娘風スライドパズル。大きな「5」と、1・2・3が記された小駒を上下左右に動かし、5を下辺中央の出口まで運びます。タップ・スワイプ・矢印ボタンで移動でき、1手戻しとリセットも可能です。
- **白い通路（PATH）**：迷路の中の光点を出口まで動かします。壁を避け、矢印か画面操作で進みます。
- **硝子の回路（GLASS）**：ボタンを押すと上下左右の光も反転する、消灯型の論理パズルです。
- **六つの反射（MIRROR）**：二行の0/1を見比べ、下側のスイッチを操作して反転関係を完成させます。
- **四枚の記憶（ORIGIN）**：点灯した板の順番を覚えて、同じ順番でタップします。

これらは異なるコードで呼び出される別々のミニゲームです。同じゲーム内のステージ2・3は**今後の追加候補**で、まだ実装していません。

## 仕組み

- スマホ／PC対応。各ミニゲームにはタッチ操作に適したボタンを設けています。
- ブラックアウト遷移、文章の逐次表示、記録のコード呼び出し。
- 通常ルートと、0/1を反転することで現れる別ルート。
- 途中で反転を忘れたときに別の問題へ進める仕組みと、最終コードの履歴照合。
