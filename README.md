# 三つの区画 / Three Gates

1つのブラウザ画面にある3つの区画へコードを入力し、謎を解きながら別の区画に進むブラウザ謎解きゲームです。現在は **v0.3（試作）** です。

## 遊び方

1. 上部のチュートリアル（全10問）を解いて、区画1を開ける最初のコードを入手します。
2. 区画1・2・3の入力欄にコードを入れると、文章、数字、暗号、仕掛けなどが現れます。
3. その謎を解くと別の区画のコードが手に入ります。各区画には複数のコードが設定されています。
4. 最下部の FINAL CODE は、ゲーム全体の解答を入力するための欄です。現在は演出の試作段階です。

## v0.3 で追加・変更したもの

- チュートリアル10問をリニューアル。矢印でつながる**等差数列・等比数列**、**五十音を「あ=1」から数える**謎、天秤、格子、立方体の展開図、鏡など、形式の異なる数値入力式の謎になりました。
- 区画1に、上下二つの矢印列が合流する謎を追加しました。
- **0と1を反転すると、反転前と別の意味を持つ解答が成立する**分岐を実装しました。二つの解答は、異なる記録につながります。
- 一度終えたチュートリアルの解答を、後半の謎で再利用する仕掛けを追加しました。
- 時刻の謎、信号の謎、数字の一本道などを追加しました。
- 仕掛け箱、暗転、文章の逐次描写、スマートフォン対応は継続しています。
