# 三つの区画 / Three Gates

1つの画面にある3つの区画へコードを入力し、それぞれの記録や仕掛けを解き進めるブラウザ謎解きゲームです。

**現行バージョン：v0.5（試作）**

## 基本ルール

- 上部のチュートリアルは、中学校～高校1年程度の基礎方程式10問です。○×ではなく、数値を直接入力します。
- チュートリアルを終えると、区画1の最初のコードが手に入ります。
- 3つの区画はコードごとに異なる謎を呼び出します。謎を解くと、次の区画または同じ区画のコードが手に入ることがあります。
- 最下段には全体の解答を送信する **FINAL CODE** が置かれています。

## v0.5 の追加要素

- 通常ルートの解答を最終コードに送信すると、**一度目の正解**を確認できるようにしました。
- 通常ルートとは別に、0と1を補数（ビット反転）として扱う **第二ルート** を追加しました。
- 第二ルートでは、ある区画で得た数値を同じ区画に入力し直すことで次の問題が開く場合があります。
- 一部の問題には、表のまま読んだ場合でも先へ進める分岐があります。**即座に不正解とは告げず**、別の問題を経由する場合もあります。
- 最終コードの送信時には、答えの文字列だけでなく、それまでの解法の記録も照合します。反転し忘れた箇所が残る場合、どこかを特定せず「まだ一致しない」旨の演出を表示します。
- 途中で取りこぼしても再挑戦できます。必要な解答の記録は同じブラウザで保存されます。

## 画面演出

画面を黒にフェードアウトしてから場面を切り替え、文章は順に書き出します。箱型の試作ギミックでは装置がフェードインします。スマートフォンにも対応しています。
