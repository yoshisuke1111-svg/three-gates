# 三つの区画 / Three Gates

3つの入口にコードを入力し、別々の記録や仕掛けを解きながら進むブラウザ謎解きゲームです。現在は **v0.4（試作）** です。

## 遊び方

1. 上部のチュートリアル（全10問）を解き、最初のコードを入手します。
2. 「1」「2」「3」の区画にはそれぞれコード入力欄があり、コードに対応した問題が出現します。
3. 謎を解くと次のコードが得られます。どの区画へ入力するかも手掛かりになります。
4. 下部の FINAL CODE はゲーム全体の解答欄です（本編はまだ制作中）。

## v0.4 の変更

- **チュートリアルは中学校～高校1年程度の簡単な方程式10問へ変更。**
- 1問目は「x² = 16」の正の解を数字で入力する形式です。
- 矢印でつながる数列、五十音表、図形、暗号などの**謎解きは本編に配置**します。
- 0と1を入れ替えて意味が変わる隠しルートを追加しました。チュートリアルの解答と途中の数字は、後半でも無関係ではありません。
- 以前のバージョンのチュートリアルコードは変更されました。進行中だった方はチュートリアルを再挑戦してください。

## 継続している要素

ブラックアウトの画面遷移、文章の逐次描写、3つのコード入力欄、試作の操作型の仕掛け箱、仮の最終解答欄。スマートフォンでも遊べます。
